# Listing image drafts

Generated from the implemented app with `python3 scripts/store-screenshots.py`
while the local server runs. No coach roster or fictional health history is
seeded. The guided view shows an actual local interaction in the capture session.

- `iphone-6.9/`: four 1320 × 2868 PNG captures.
- `android-phone/`: four 1080 × 1920 PNG captures.
- `play-feature-graphic.png`: 1024 × 500 promotional graphic.
- Native app icon: the project's opaque 1024 × 1024 iOS artwork and Android

These are browser captures of the packaged web UI, not physical-device
evidence. Check parity with the signed iPhone/Android builds, visible
platform UI and current console image requirements during QA. Replace any
capture that differs from the actual release. No native iPad target is
enabled; do not upload iPad screenshots or claim iPad-native support.
